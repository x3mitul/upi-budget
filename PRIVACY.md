# Privacy

UPI Budget is a personal Android app. It is not published on any app store and there is no company or server behind it.

- It reads bank SMS, notifications from UPI payment apps on the phone, and (only if you connect it) the Gmail inbox of the signed-in Google account, read-only, limited to bank alert emails.
- All data is stored in a database on the phone and is not backed up to any cloud. Export and import are manual files you control.
- It sends no analytics, crash reports or personal data anywhere. The only network request is to Google's Gmail API to read your own mailbox, and only if you turn that on.
- You can revoke Gmail access at any time at https://myaccount.google.com/permissions.
